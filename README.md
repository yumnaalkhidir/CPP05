# CPP05

42 School C++ Module 05 — repetition and exceptions via a Bureaucrat/Form hierarchy.

## Concepts covered
- Custom exception classes and exception safety
- The Bureaucrat/Form approval-chain hierarchy
- Three concrete Forms and an Intern factory

## Exercises
ex00 ex01 ex02 ex03 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
